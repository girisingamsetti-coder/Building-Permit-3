ADD A NEW ROLE: PROJECT MANAGER

Create a new dedicated account/role called:

PROJECT MANAGER

This role must be integrated into the existing LTP Approval /
Building Permit Management System RBAC architecture.

IMPORTANT:

Do NOT replace the existing Administrator.

Do NOT give Project Manager Administrator permissions.

Do NOT give Project Manager authority to modify:

- Roles
- Permissions
- Users
- Fee Structures
- System Settings
- Workflow Configuration
- Application Types

Do NOT give Project Manager approval/rejection authority unless explicitly
configured later.

The Project Manager is primarily a:

MONITORING
TRACKING
REPORTING
COORDINATION

role.

==================================================
1. PROJECT MANAGER OBJECTIVE
==================================================

The Project Manager should be able to see the overall operation of the
Building Permit Approval Workflow.

The account holder should be able to see:

- all applications
- all workflow stages
- progress of individual applications
- current stage
- assigned officer
- role responsible
- pending actions
- completed actions
- delays
- SLA status
- shortfalls
- scrutiny status
- document status
- fee status
- payment status
- overall approval progress

The Project Manager should be able to drill down from:

Overall Project View
↓
Application
↓
Workflow
↓
Individual Stage
↓
Responsible User / Officer
↓
Activity / Action History
