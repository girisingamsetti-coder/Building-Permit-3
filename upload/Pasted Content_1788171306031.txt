Redesign the ENTIRE Drawings & Scrutiny module of the existing
LTP Approval / Building Permit Management System.

IMPORTANT:

This is a UI/UX redesign plus functional cleanup for ONLY the
Drawings & Scrutiny module.

Do NOT redesign:
- Dashboard
- My Applications
- Documents
- Fees
- Payments
- Shortfalls
- Notifications
- Help & Support
- Administration
- Authentication

Do NOT change the core business workflow.

Do NOT remove existing drawing, scrutiny, versioning, upload, report,
or application functionality.

The goal is to replace the current messy Drawings & Scrutiny interface
with a clean, professional, modern government-enterprise interface with:

- perfect alignment
- consistent widths
- consistent spacing
- clean hierarchy
- no overlapping elements
- no excessive empty space
- clear application context
- clear drawing viewer
- clear upload workflow
- clear version history
- clear scrutiny status
- clear scrutiny report
- responsive design

==================================================
1. CURRENT PROBLEM
==================================================

The current Drawings & Scrutiny page is visually crowded.

Problems to fix:

- too many competing areas
- inconsistent card widths
- uneven spacing
- drawing viewer does not dominate enough
- upload card feels disconnected
- version history is visually cramped
- scrutiny summary is separated from the main workflow
- application information is repeated unnecessarily
- action buttons are not organized clearly
- page has inconsistent vertical rhythm
- some sections have too much blank space
- some sections are too compressed
- visual hierarchy is weak

Redesign the page structure from the ground up while preserving existing functionality.
